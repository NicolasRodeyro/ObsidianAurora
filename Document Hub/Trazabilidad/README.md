# Trazabilidad — Artefactos por Historia

Esta carpeta contiene un **artefacto de trazabilidad por Historia de Usuario** (formato de la cátedra): conecta cada historia con sus decisiones de diseño (ADR), modelo de datos (DER), diagramas de modelado, código y casos de prueba.

- Generar cada artefacto con la skill **`$artefacto-trazabilidad`** (en `.agents/skills/artefacto-trazabilidad/`).
- La fuente de verdad por sprint es `INSTANCIA 3 — Sprints 1 a N/Sprint <N>/<KEY>/Artefacto de trazabilidad - <KEY>.md`. Esta carpeta conserva ejemplos o material transversal.
- Para la trazabilidad a nivel **requerimiento → épica**, ver [[Trazabilidad RF-Épicas]].

> Aún sin artefactos: se irán creando a medida que se descompongan las épicas en historias y se desarrollen.
